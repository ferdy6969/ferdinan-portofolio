A developer-centric, anti-slop portfolio inspired by GitHub's dark mode and Network Operation Center (NOC) dashboards.

PublicMTCRENSE 2

🛠️ Tech Stack & Concepts
UI/UX: GitHub Dark Mode Primer Design System (Anti-Slop).
Frontend: Vanilla HTML5, CSS3, Vanilla JavaScript (No frameworks, zero dependencies).
Interactive Terminal: Custom CLI logic with command history (Arrow Up/Down).
Topology Canvas: HTML5 Canvas API for packet routing visualization.
Uptime Heatmap: CV-mapped contribution graph representing 10+ years of career uptime.
AI NOC: Rules-based chatbot mapped to CV experience.
💻 Terminal Commands
Type help in the terminal tab to see available commands:

about - Know more about me
skills - List my technical stack
experience - View my work history (Git Commit style)
contact - Get my contact details
